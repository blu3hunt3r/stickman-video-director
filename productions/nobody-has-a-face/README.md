# Nobody Has a Face — a stickman noir

A 2:58.8 vertical (9:16) crime thriller directed with this repository's
[`directing-stickman-videos`](../../skills/directing-stickman-videos/SKILL.md) skill in
**Style 1 Dark** (white faceless line figures on a flat pitch-black canvas, three accent colors),
and rendered entirely in code.

> *Seven witnesses saw the killer's face. Not one of them could describe it.
> Because in this city... nobody has a face.*

## How it was made

* **Director (this session):** story, script and Phase A proposal, narration generation and timeline lock,
  the animation engine, scene S01, integration, QA and delivery.
* **Six animator agents** built S02–S18 against the engine and the bible (three scenes each, S14–S15 as a pair),
  checking every cut frame against its neighbour; **one sound agent** built the score, SFX, ambience and mixer.
* Magnific was used only for the narration (ElevenLabs Turbo v2.5, ~312 credits including a voice test).

## Layout

```
engine/     camera, frame compositing (light-reveal masks, glow, blur), the stick-figure rig
            (frozen Style 1 anchor), props, sets, fx, renderer
scenes/     s01_lineup.py ... s18_verdict.py — one module per scene: render(f, t, T) + cues(T)
audio/      dsp, sfx library, ambience beds, score, mixer   (audio/vo/ holds the narration WAV)
timeline/   word timings + locked timeline
tools/      captions.py (SRT/ASS), assemble.py (render → mix → mux → QA)
```

## Rebuild

```bash
cd productions/nobody-has-a-face
pip install pycairo scipy numpy pillow
python3 -m engine.render s07 --sheet 12        # contact sheet of one scene -> qa/
python3 tools/assemble.py all                   # render all scenes, mix, mux finals, QA
```

The narration file is not regenerated by the build; place the 48 kHz WAV of the Magnific take at
`audio/vo/narration_full.wav` before mixing.
