# Nobody Has a Face — a stickman noir

A 2:58.8 vertical (9:16) crime thriller directed with this repository's
[`directing-stickman-videos`](../../skills/directing-stickman-videos/SKILL.md) skill in
**Style 1 Dark** (white faceless line figures on a flat pitch-black canvas, three accent colors),
and rendered entirely in code.

> *Seven witnesses saw the killer's face. Not one of them could describe it.
> Because in this city... nobody has a face.*

| | |
|---|---|
| Format | 1080×1920, 24 fps, H.264 + AAC 48 kHz, 4,292 frames (178.83 s — under the 3:00 Shorts/Reels cap) |
| Style | Style 1 Dark (faceless anchor), accents: streetlamp amber · blood crimson · siren blue |
| Narration | Magnific → ElevenLabs **Turbo v2.5** (the cheap voice tier), catalog voice *Noah Reed*, one continuous take, stability 0.5 / similarity 0.8 / speed 0.95 |
| Everything else | procedural: 2D animation engine (pycairo), score, sound effects, ambience and mix (numpy/scipy) — no other AI or stock media |
| Story structure | the skill's five-stage heartbeat engine: hook → disrupted assumptions → insider secrets → truth → elevation + comment question |

## Deliverables (`final/`)

* `nobody-has-a-face_9x16.mp4` — the clean master (no text in picture, per the style contract)
* `nobody-has-a-face_9x16_captioned.mp4` — social cut with burned-in captions and the two optional overlays from the bible (title card, "GUILTY OR FRAMED?")
* `nobody-has-a-face.en.srt` — caption file for platform upload
* `poster.png` — thumbnail frame

## Production documents

* [`docs/production-bible.md`](docs/production-bible.md) — the director's proposal (Phase A): logline, frozen voice block, palette, cast/prop continuity, 18-row storyboard, scene beat sheets, the continuity connection for every cut, ambience map and score plan.

## Layout

```
engine/     camera, frame compositing (light-reveal masks, glow, blur), the stick-figure rig
            (frozen Style 1 anchor), props, sets, fx, renderer
scenes/     s01_lineup.py ... s18_verdict.py — one module per scene: render(f, t, T) + cues(T)
audio/      dsp, sfx library, ambience beds, score, mixer   (audio/vo/ holds the narration WAV)
timeline/   word timings + locked timeline
tools/      captions.py (SRT/ASS), assemble.py (render → mix → mux → QA)
```

## Rebuild

```bash
cd productions/nobody-has-a-face
pip install pycairo scipy numpy pillow
python3 -m engine.render s07 --sheet 12        # contact sheet of one scene -> qa/
python3 tools/assemble.py all                   # render all scenes, mix, mux finals, QA
```

The narration file is not regenerated by the build; place the 48 kHz WAV of the Magnific take at
`audio/vo/narration_full.wav` before mixing.
